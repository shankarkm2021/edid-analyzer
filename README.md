# HDMI EDID Analyzer

A comprehensive tool for parsing and analyzing EDID (Extended Display Identification Data) from HDMI devices. Perfect for testing display capabilities and HDMI interoperability.

## Features

- 🔍 Parse EDID headers and manufacturer information
- 📊 Extract display capabilities (resolution, timing, color depth)
- ✅ Validate EDID checksums
- 🎯 Detect HDMI-specific capabilities (Deep Color, 3D, etc.)
- 📝 Generate human-readable reports
- 🔧 Support for reading from files, hex strings, or I2C devices
